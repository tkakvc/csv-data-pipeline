# 取込CSVフォーマット仕様

各部門が支出した経費データを対象とする。1行が1件の支出明細に対応する。

## 1. CSVの列定義

| 列番号 | 列名（日本語ヘッダー） | 説明 | 型 | 例 | 必須 |
|---|---|---|---|---|---|
| 1 | 利用日 | 支出が発生した日 | `YYYY-MM-DD` | `2026-07-01` | 必須 |
| 2 | 部門コード | 部門を識別するコード | 英数字（最大50文字） | `SALES` | 必須 |
| 3 | 部門名 | 部門の表示名 | 文字列（最大100文字） | `営業部` | 必須 |
| 4 | 勘定科目 | 支出のカテゴリ | 文字列（最大100文字） | `交通費` | 必須 |
| 5 | 金額 | 支出額（円、税込、整数） | 整数（0以上） | `3200` | 必須 |
| 6 | 取引先 | 支払先の名称 | 文字列（最大255文字） | `JR東日本` | 任意 |
| 7 | 摘要 | 支出の内容についての自由記述 | 文字列 | `顧客訪問のための移動` | 任意 |

## 2. サンプルCSV

```csv
利用日,部門コード,部門名,勘定科目,金額,取引先,摘要
2026-07-01,SALES,営業部,交通費,3200,JR東日本,顧客訪問のための移動
2026-07-01,DEV,開発部,通信費,8800,NTTドコモ,業務用回線
2026-07-02,SALES,営業部,会議費,15000,スターバックス,顧客打ち合わせ
2026-07-03,HR,人事部,消耗品費,4500,Amazon,オフィス用品
2026-07-05,SALES,営業部,交通費,1500,JR東日本,顧客訪問のための移動
2026-08-01,DEV,開発部,通信費,8800,NTTドコモ,業務用回線
```

## 3. バリデーションルール

- 拡張子：`.csv`以外は受け付けない
- 文字コード：UTF-8（BOM付きも許容する）
- ヘッダー行：1行目は必ず上記7列のヘッダーとし、列の順序・列数が一致しない場合はエラーとする
- 各行のバリデーション
  - 利用日：`YYYY-MM-DD`形式でパースできない場合はその行をエラー扱いにする
  - 部門コード・部門名・勘定科目：空文字は不可
  - 金額：整数に変換できない、または負数の場合はエラー
  - 取引先・摘要：空文字を許容する（NULL可）
- ファイルサイズ上限：10MB
- 1行でもエラーがあった場合の扱い：ファイル全体を取り込まず、`upload_audit_log`に失敗理由を記録する（部分的な取込はしない。中途半端な集計を避けるため）

## 4. このCSVが取り込まれた後の変換イメージ

```
CSV 1行目：2026-07-01,SALES,営業部,交通費,3200,JR東日本,顧客訪問のための移動
      ↓（そのままraw_expensesにINSERT）
raw_expenses:
  usage_date=2026-07-01, department_code=SALES, department_name=営業部,
  account_category=交通費, amount=3200, vendor=JR東日本, description=顧客訪問のための移動

CSV 1〜2行目（同じ2026-07月・SALES・交通費のデータが複数ある場合）
      ↓（月・部門・勘定科目ごとに金額を合計してsummary_expensesにUPSERT）
summary_expenses:
  usage_month=2026-07-01, department_code=SALES, account_category=交通費, total_amount=4700
```
